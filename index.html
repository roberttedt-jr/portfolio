ATMOS — Weather Mode

01 / OVERVIEW

Reinventando la experiencia meteorológica en la web

ATMOS nació como un proyecto en UNIVERSAE orientado a explorar las capacidades de las aplicaciones web progresivas (PWA) de alto rendimiento. El propósito fue diseñar una herramienta climática que combinase una estética minimalista con datos hiperprecisos y visualización en tiempo real.

02 / ARCHITECTURE & TECH STACK

Estructura moderna sin dependencias pesadas

La arquitectura se construyó sobre JavaScript puro (Vanilla), HTML5 semántico y CSS3 con técnicas avanzadas de desenfoque por capas. Se implementó una integración directa con la API pública de Windy para la recepción continua de variables de presión, viento y proyecciones térmicas.

03 / LIQUID GLASS UI

Inmersión visual reactiva al clima

La interfaz adopta un gradiente dinámico inspirado en la luminosidad del cielo mediterráneo. Cada tarjeta y gráfica vectorial SVG responde fluidamente al tamaño del dispositivo, manteniendo una legibilidad cristalina tanto en escritorio como en navegadores móviles.
