## 📖 Sobre el Portfolio

Este repositorio contiene el código fuente de mi **portfolio personal interactivo**, diseñado con una estética minimalista y editorial de alta gama (*Dark Mode*). 

Sirve como escaparate profesional para presentar proyectos de ingeniería de software, arquitectura de sistemas, telemetría y aplicaciones web/móviles en tiempo real, junto con mi trayectoria académica y enlace de descarga a mi Curriculum Vitae actualizado en formato PDF.

## 🎨 Diseño y Estética

El portfolio está concebido con un estándar visual contemporáneo y tipografía editorial cuidada:

- **Paleta de Color Oscura:** Fondos `#0c0c0e` con acentos de luz ambiental (*hero spotlight*) y contraste adaptado a legibilidad prolongada.
- **Tipografías:**
  - *Neue Montreal* para texto corrido y ergonomía de lectura.
  - *Geist* para elementos técnicos y datos cuantitativos.
  - *Gloock* y *Newsreader* para titulares editoriales y acentos de diseño.
- **Interactividad Fluida:** Animaciones sutiles, microinteracciones en tarjetas de proyectos, selector de idioma (ES/EN) y visualización de capturas responsive en alta definición.

## 💻 Ejecución y Visualización Local

Al tratarse de una solución estática nativa optimizada (HTML5 + Tailwind CDN + Vanilla JS), no requiere procesos de compilación pesados:

### 1. Clonar el Repositorio
```bash
git clone https://github.com/roberttedt-jr/portfolio.git
cd portfolio
```

### 2. Abrir con cualquier servidor local
Puedes abrir directamente el archivo `index.html` en tu navegador, o levantarlo con un servidor ligero:

```bash
# Con npx serve
npx serve .

# O con Python 3
python -m http.server 3000
```
Visita [http://localhost:3000](http://localhost:3000).
